# 2026-09-15 — Phase 3: theme/ прошивка цветов через все компоненты

> [!info] Мета
> **Дата:** 2026-09-15 · **Тип:** `phase` · **Статус:** ✅ завершено
> **Коммит:** `61bf233` · **Ветка:** `main`

## Цель

Прошить `theme/colors.nix` через все компоненты, которые использовали hardcoded цвета: Waybar, Neovim, Alacritty, Kitty, Yazi.

## Что сделано

### Waybar style.nix
- **`home/features/desktop/bar/style.nix`** — конвертирован в Nix-функцию `{ theme, ... }`. Все hardcoded цвета заменены на `theme.colors`:
  - `#001a0d` → `theme.colors.bg`
  - `#C0FFC0` → `theme.colors.fg`
  - `#CC66FF` → `theme.colors.secondary`
  - `#33FFB2` → `theme.colors.success`
  - `#FFD500` → `theme.colors.warning`
  - `#00BFFF` → `theme.colors.accentBlue`
  - `#FF007C` → `theme.colors.error`
  - `rgba(30, 30, 46, ...)` → `theme.colors.bgAltTransparent`
  - `rgba(0, 26, 13, ...)` → `theme.colors.bgTransparent`
- **`home/features/desktop/bar/waybar.nix`** — добавлен `theme` в функцию, передаётся в `style.nix`.

### Neovim
- **`home/features/cli/neovim/init.nix`** — добавлен `theme` в функцию. Создаёт `artgreendream.lua` через `home.file` с `theme.colors`. Удалён статический `artgreendream.lua`.
- **`home/features/cli/neovim/lua/plugins/lualine.nix`** — все цвета заменены на `theme.colors`. Добавлен `theme` в функцию.
- **`home/features/cli/neovim/lua/plugins/default.nix`** — добавлен `theme` в функцию.
- **`home/features/cli/neovim/default.nix`** — добавлен `theme` в функцию.

### Alacritty
- **`home/features/cli/terminal/alacritty.nix`** — все цвета заменены на `theme.colors`. Добавлен `theme` в функцию.

### Kitty
- **`home/features/cli/terminal/kitty.nix`** — все цвета в `extraConfig` заменены на `theme.colors`. Добавлен `theme` в функцию.

### Yazi
- **`home/features/cli/yazi.nix`** — секция `theme` заменена на `theme.colors`. Добавлен `theme` в функцию.

## Удалено
- `home/features/cli/neovim/nvim/colors/artgreendream.lua` — заменён на Nix-генерацию
- `home/features/cli/neovim/nvim/colors/artgreendream.nix` — заменён на `init.nix`

## Результат
- `nix flake check` — **проходит** без ошибок
- Все компоненты используют единый источник цветов `theme/colors.nix`

## Решения
- **Waybar CSS** — Nix-функция вместо статического CSS
- **Neovim colorscheme** — генерируется из `theme.colors` через `home.file`
- **Alacritty/Kitty** — `theme.colors` в настройках
- **Yazi** — `theme.colors` в секции `theme`
