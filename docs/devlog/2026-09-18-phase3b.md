# 2026-09-18 — Phase 3b: theme/ прошивка цветов + сервисы

> [!info] Мета
> **Дата:** 2026-09-18 · **Тип:** `feature` · **Статус:** ✅ evaluation OK

## Цель

Завершить Phase 3 — заменить оставшиеся хардкодные цвета в Neovim-плагинах на `theme.colors`. Настроить Tailscale, Tor и OpenVPN конфигурацию.

## Что сделано

### theme/ прошивка цветов

- `home/features/cli/neovim/lua/plugins/cmp.nix` — `#F77248` → `c.error`
- `home/features/cli/neovim/lua/plugins/noice.nix` — `#66FF99` → `c.primary`, `#58FFD6` → `c.accentBlue`
- `home/features/cli/neovim/lua/plugins/bufferline.nix` — `#00ff99` → `c.primary`, `#EF5350` → `c.error`
- Все три плагина теперь принимают `{ theme, ... }` и используют `theme.colors`

### Сервисы

- **Tailscale**: добавлен `authKeyFile` из переменной окружения `TAILSCALE_AUTHKEY_FILE`
- **Tor**: добавлен `settings` с `HiddenServiceDir` и `HiddenServicePort` для hidden services
- **OpenVPN**: создана структура `system/openvpn/client/example.conf`

### Конфигурация

- `system/services.nix` — обновлён (Tailscale authKeyFile, Tor settings, OpenVPN etc.)
- `system/openvpn/client/example.conf` — шаблон клиентского конфига

## Результат

- `nix flake check` проходит без ошибок
- Все компоненты используют единственный источник цветов `theme/colors.nix`
- Сервисы (Tailscale, Tor, OpenVPN) настроены и готовы к заполнению реальными данными

## Решения

- Для Tailscale используется `authKeyFile` (а не `authKey`) — опция принимает `types.path`
- Для Tor hidden services используется `services.tor.settings` (torrc директивы), а не `relay.onionServices` (который только для `clientAuthorizations`)
- Для OpenVPN используется `environment.etc` с source-файлом

## Открытые вопросы

- [ ] Заполнить `TAILSCALE_AUTHKEY_FILE` реальным ключом
- [ ] Заполнить OpenVPN `example.conf` реальными данными сервера
- [ ] Настроить Tor hidden services при необходимости
