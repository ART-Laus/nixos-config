# 2026-09-15 — Phase 1: полная иерархия features сразу

> [!info] Мета
> **Дата:** 2026-09-15 · **Тип:** `phase` · **Статус:** ✅ завершено (evaluation OK)
> **Коммит:** `c5a551f` · **Ветка:** `main` · **Flake:** `nixos-25.05` + `home-manager 25.05`

## Цель

Реализовать **полную иерархию сразу** (по запросу «всё сразу там, где должны быть»), без отложенного расщепления. Перевести систему из `artlaus/` WSL-миграции в конструктор `hosts + system + home/features + theme`.

## Что сделано

> [!success] Структурa — 75 файлов изменено, 4151+ вставок

### Hosts
- `hosts/msi-laptop/default.nix` — единая точка входа, импортирует `system/*`
- `hosts/msi-laptop/hardware-configuration.nix` — заглушка (заменить на `nixos-generate-config` на железе)

### System (было: `system/packages.nix` 266 строк монолит)
- `system/nix.nix` — `nix.settings` (substituters, cachix), `gc` weekly, `optimise`, `allowUnfree`
- `system/boot-hardware.nix` — `systemd-boot`, `linuxPackages_latest`, `hardware.graphics` (amdgpu), `pipewire`+`wireplumber`, `bluetooth`, `power-profiles-daemon`, `logind` lid, `fwupd`
- `system/networking-security.nix` — `NetworkManager`, `firewall`, `timeZone`, `users.artlaus` (zsh shell), `programs.zsh.enable`, `gnupg`, `polkit` (один агент)
- `system/services.nix` — `greetd`+`tuigreet` (утверждено), `xdg.portal` (hyprland+gtk, `config.common.default="*"`), `thunar`, `ollama` (`127.0.0.1`, `rocmOverrideGfx=10.3.0`), `nix-ld`, `appimage`
- `system/gaming.nix` — `steam`, `gamemode`, `gamescope`, `wine`, `vulkan` (флаг `features.gaming`)
- `system/virtualization.nix` — `docker` (флаг `features.virtualization`)
- `system/packages.nix` — минимальный остаток (fonts + core CLI)

### Flake
- Обновлён с `23.11` (EOL) до `25.05` + `nixpkgs-unstable`
- `specialArgs = { inherit inputs theme username; pkgs2=pkgs; spkgs=pkgs; }` — совместимость со старыми `pkgs2`
- `theme = import ./theme` — единый источник (`theme/colors.nix`, `fonts.nix`)
- `hyprland` без `hypr-niri` (плагин убран, чистый Hyprland)
- `legacy` (`msi-laptop-legacy`) удалён — теперь только `msi-laptop` + `homeConfigurations`

### Home — полная иерархия `home/features/*` (было: `artlaus/features` + `system/home.nix` двойной импорт)
- `home/default.nix` — импортирует `features/*` + `gtk-qt.nix`, `options.artlaus.cli.enable` compat (default true)
- `home/gtk-qt.nix` — `adw-gtk3-dark`, `Papirus-Dark`, `Bibata`, `qt6ct`+`kvantum` (`qt.platformTheme.name="qt6ct"`)
- `home/features/cli/*` — `shell/zsh.nix`+`starship.nix`, `terminal/wezterm.nix`+`alacritty.nix`, `git.nix`, `yazi.nix`, `tmux.nix`, `neofetch.nix`, `tools.nix`, `neovim/*`
- `home/features/desktop/*` — `compositor/hyprland.nix` (переписан на Home Manager `wayland.windowManager.hyprland`, тема из `theme`), `compositor/hyprpaper.nix`, `bar/waybar.nix`+`style.nix`+`scripts`, `launcher/rofi.nix` (тема из `theme`), `notifications/dunst.nix`, `lockscreen/swaylock.nix`+`swayidle.nix`, `browsers.nix`
- `home/features/development`, `media`, `gaming` — заглушки с базовыми пакетами

### Neovim
- `home/features/cli/neovim` — `Lazy.nvim` (утверждено), `init.nix` (extraLuaConfig для mapleader), `artgreendream.lua` восстановлен из удалённого коммита `5e69bf5` (`/tmp/recover`)

### Theme
- `theme/colors.nix` + `fonts.nix` + `default.nix` + `lib/theme.nix` (`toRgba`) — единый источник, прокинут через `specialArgs.theme`

- `git`: `editor`→`extraConfig.core.editor`, `neofetch` module removed (package only), `neovim globals`→`extraLuaConfig`
