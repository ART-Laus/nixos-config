# 2026-09-15 — Phase 2: удаление artlaus/, nix flake check, фикс devShell

> [!info] Мета
> **Дата:** 2026-09-15 · **Тип:** `phase` · **Статус:** ✅ завершено
> **Коммит:** `bdbbac3` · **Ветка:** `main`

## Цель

Завершить миграцию: удалить артефакты WSL-миграции (`artlaus/`, `system/home.nix`, `system/configuration.nix`), убедиться что `nix flake check` проходит, зафиксировать devShell.

## Что сделано

### Удаление мёртвого кода
- **`artlaus/`** — удалён полностью (20MB, 1484 файла). Содержал вендорированные `oh-my-zsh/` (18МБ), `.antidote/` (1.4МБ), `.zsh_history`, `.zcompdump`, `.zshenv`. Вся функциональность перенесена в `home/features/cli/*` в Phase 1.
- **`system/home.nix`** — удалён. Это был файл с `imports = [ ../artlaus ]`, создающий двойной импорт home-модуля в NixOS (K3 из аудита). Home Manager теперь подключается только через `flake.nix` → `home-manager.nixosModules.home-manager`.
- **`system/configuration.nix`** — удалён. Заменён модульной структурой: `hosts/msi-laptop/default.nix` импортирует `system/nix.nix`, `system/boot-hardware.nix`, `system/networking-security.nix`, `system/services.nix`, `system/gaming.nix`, `system/virtualization.nix`, `system/packages.nix` напрямую.

### Фикс devShell
- `nixpkgs-fmt` → не существует в nixpkgs 25.05 → заменён на `nix`
- `nil`, `home-manager` → не в `pkgs` → убраны из devShell (доступны через `nix shell` при необходимости)
- devShell теперь содержит только `nix` и `git` — оба доступны в `pkgs`

### Проверка
- `nix flake check` — **проходит** без ошибок
- `nix eval .#nixosConfigurations.msi-laptop.config.system.build.toplevel.drvPath` — OK
- `nix eval .#homeConfigurations.artlaus.activationPackage.drvPath` — OK

## Результат

> ```bash
> nix flake check
> # → derivation evaluated to /nix/store/...-nix-shell.drv  (OK)
> ```

- **0 ошибок** при `nix flake check`

## Решения

- **`artlaus/` удалён полностью** — не нужно сохранять для истории, `home/features/cli/*` покрывает всё
- **`system/home.nix` и `system/configuration.nix` удалены** — заменены модульной структурой Phase 1
- **devShell упрощён** — `nix` + `git` вместо несуществующих `nixpkgs-fmt`/`nil`/`home-manager`
