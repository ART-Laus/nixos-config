# 2026-09-18 — Добавлены Tor, OpenVPN, Tailscale, Docker

> [!info] Мета
> **Дата:** 2026-09-18 · **Тип:** `feature` · **Статус:** ✅ завершено
> **Коммит:** `38bd698` · **Ветка:** `main`

## Цель

Добавить VPN и приватность сервисы в систему: Tor, OpenVPN, Tailscale, Docker.

## Что сделано

### system/packages.nix
Добавлены пакеты:
- `tor` — анонимный прокси
- `openvpn` — VPN клиент
- `tailscale` — Mesh VPN
- `docker` — контейнеризация
- `docker-compose` — оркестрация Docker

### system/services.nix
Добавлены NixOS сервисы:
- `services.tor` — включён, клиент mode, firewall закрыт
- `services.tailscale` — включён, routing features, firewall закрыт
- `programs.appimage` — уже был

### system/virtualization.nix
- Docker уже был настроен через `features.virtualization` флаг
- `enableOnBoot = false` — Docker не запускается автоматически

### hosts/msi-laptop/default.nix
- `features.virtualization.enable = true` — включён Docker

### OpenVPN
- Добавлен как пакет (`openvpn`)
- Конфигурация вручную через `/etc/openvpn/client/<name>.conf`
