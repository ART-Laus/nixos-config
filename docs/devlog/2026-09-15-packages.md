# 2026-09-15 — Миграция system/packages.legacy

> [!info] Мета
> **Дата:** 2026-09-15 · **Тип:** `packages-migration` · **Статус:** ✅ завершено (evaluation OK)

## Цель
Разложить монолитный `system/packages.nix` (266 строк, ~150 пакетов) по категориям в `home/features/*`, убрав зависимость от `pkgs2`.

## Раскладка пакетов

| Куда | Что переехало |
|---|---|
| `home/features/development/default.nix` | Gamedev: godot, gdtoolkit_4, ldtk; API/DB: dbeaver, pgadmin4, postman, insomnia; drawio, xournalpp |
| `home/features/media/default.nix` | mpv, imv, qview, feh, obs-studio, strawberry, easyeffects; Docs: evince, libreoffice, calibre, hunspell+ru_RU+en_US; Design: krita, gimp3, gcolor3; Productivity: obsidian, planify; ksnip, screenkey, qbittorrent |
| `home/features/desktop/apps.nix` (новый) | ranger, xfce.{thunar, catfish, exo}, file-roller, ffmpegthumbnailer, gnome-epub-thumbnailer, f3d, openscad, networkmanagerapplet, brightnessctl, qmk, vial |
| `home/features/desktop/browsers.nix` | + thunderbird, discord, telegram-desktop |
| `system/gaming.nix` | Полный vulkan-набор: vulkan-tools{-lunarg}, headers, validation-layers, utility libs, extension-layer, gfxreconstruct, glslang, spirv-*, vkdisplayinfo, vk-bootstrap, dxvk, vkd3d{-proton} |
| `system/packages.nix` | Осталось: системные либы форматов (imagemagick/kimageformats/webp/avif/heif/jxl/raw/poppler...), icons (breeze, material, gruvbox-plus), hardware utils (pciutils, usbutils, lm_sensors, libva-utils, clinfo, alsa-utils), core CLI |

## Прочее
- `initExtra` → `initContent` и в `artlaus/features/cli/zsh/zsh.nix`, и в `home/features/cli/shell/zsh.nix` (убран deprecation-warning)
- Убраны дубли `spirv-tools`/`glslang` в `system/gaming.nix`
- Убрана зависимость от `pkgs2.*` (godot, gdtoolkit, calibre, discord — все в `pkgs`)
