## Цель

Тотальный аудит перед переустановкой на реальное железо. Ответить на два вопроса: *«Работает ли система правильно?»* и *«Насколько хорошо спроектирована как единый продукт?»*

## Что сделано

- Изучены 51 Nix-файл + скрипты + вендоренные директории (18М `oh-my-zsh`, 1.4М `antidote`)
- Проверены `flake.nix`, `system/*`, `artlaus/features/**`, `home.nix`, `lib/*`, `modules/*`, `scripts/*`
- Найдены критические блокеры сборки
  - `pkgs2` / `spkgs` / `inputs` undefined
  - двойной импорт `../artlaus` (System → Home)
  - `stylix` без модуля
  - `artgreendream` без темы
  - LSP API 0.11 vs 0.9.5
- Найдены блокеры реального железа
  - нет `fileSystems`, `pipewire`, `display-manager`, `hardware.graphics`
  - `GRUB` на `/dev/sda`
  - WSL-артефакты `wsl.exe` в `alacritty`/`wezterm`
- Оценены дизайн-система, TUI/CLI, Git, безопасность, производительность
